보험 용어사전

설명에서 자주 만나는 핵심 용어를 쉽게 정리했습니다. 용어를 누르면 상세 페이지로 이어집니다.

고지의무 (계약 전 알릴 의무)

청약할 때 보험회사가 질문한 중요한 사항을 사실대로 알려야 하는 의무. 위반하면 계약이 해지되거나 보험금이 지급되지 않을 수 있습니다.

상세 설명 →

간편고지

보험회사가 정한 질문으로 건강 상태를 확인하는 심사 방식입니다. 질문이 짧아도 빠짐없이 답해야 하며 질문 기간과 인수 조건은 가입시기·상품에 따라 다릅니다.

상세 설명 →

보장개시일

보험회사의 보장 책임이 시작되는 날. 암 보장처럼 별도의 대기기간이 있는 담보도 있습니다.

상세 설명 →

갱신형

정해진 주기에 계약을 갱신하며 보험료를 다시 산정하는 구조입니다. 나이와 위험률 등의 변화로 보험료가 달라질 수 있습니다. 갱신 주기와 종료 조건은 가입시기·상품에 따라 다릅니다.

상세 설명 →

비갱신형

정한 납입기간 동안 약정된 보험료를 내는 구조입니다. 주계약과 특약의 갱신 여부를 각각 확인하며, 계약 변경에 따른 보험료 변동은 별도로 살펴봅니다.

상세 설명 →

무해지환급형

정해진 기간에 해지하면 해지환급금이 없거나 적게 설계된 구조입니다. 납입이 끝난 뒤의 환급 방식도 가입시기·상품에 따라 다릅니다.

상세 설명 →

실손의료비

실제 부담한 의료비를 약관 기준에 따라 보상하는 보험. 가입 시기에 따라 자기부담금과 보상 조건이 다릅니다.

상세 설명 →

납입면제

약관에서 정한 사유가 생기면 이후 보험료를 내지 않아도 보장이 유지되는 기능.

상세 설명 →

부담보

특정 부위나 질병을 일정 기간 또는 전 기간 보장에서 빼고 인수하는 조건.

상세 설명 →

실효

보험료가 연체되고 정해진 납입최고 절차를 거쳐 계약의 효력이 끝난 상태를 뜻합니다. 자동이체 실패만으로 즉시 실효된 것으로 단정하지 말고 계약 상태를 확인합니다.

상세 설명 →

부활

보험료 연체로 해지된 계약을 정해진 요건에 따라 다시 유지하는 절차입니다. 신청 기간, 미납 보험료 납입, 고지와 심사 조건은 가입시기·상품에 따라 다릅니다.

상세 설명 →

청약철회

가입 후 정해진 기간과 요건 안에서 청약 의사를 거두는 제도입니다. 적용 대상과 예외, 기간의 계산 기준은 계약 서류로 확인합니다. 단순 해지와 구별해야 합니다.

상세 설명 →

원수사

보험상품을 직접 만들고 보험금을 지급하는 보험회사.

상세 설명 →

GA (법인보험대리점)

여러 보험회사의 계약 체결을 대리하는 법인보험대리점입니다. 상품을 만드는 보험회사와 판매를 대리하는 조직의 역할을 구분하며 실제 취급 범위는 제휴 관계에 따라 다릅니다.

상세 설명 →

AP (Approach)

세일즈 2단계. 신뢰를 만들고 분위기를 전환하는 접근 단계.

상세 설명 →

FF (Fact Finding)

세일즈 4단계. 병력·가족력·기존 보험·예산을 파악하는 정보 수집 단계.

상세 설명 →

PT (Presentation)

세일즈 5단계. 검토를 끝낸 설계안을 제안하는 단계.

상세 설명 →

CL (Closing)

세일즈 6단계. 앞선 과정을 확인하며 계약으로 마무리하는 단계.
